An entry for make.fun's "The One-Line Laugh" competition. It writes a single original funny sentence built around an everyday truth with a surprise twist at the end, validates that the line is one sentence of 1–200 characters, and saves it deterministically so repeated runs produce byte-identical output.

## Run

```sh
python3 main.py
```

It writes the line to /output/entry.txt.
